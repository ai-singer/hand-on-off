# Template A: Industry Chain Analysis (产业链拆解型)

Inspired by: 一天吃透一条产业链 NO.87

**Applicable scenarios:**
- Any industry with upstream/downstream structure
- Supply chain economics
- Platform/ecosystem business models

## Title Pattern
```
一天吃透一条产业链 NO.{N} {行业名称}产业链
一口气看懂{行业名称}的钱怎么流动的
{行业名称}背后的产业链，比你想的复杂多了
```

## Hook Pattern
```
[→] {行业名称}产业链是围绕{核心资产}构建的
"{上游动作} - {中游动作} - {下游动作}"闭环，
核心呈现"{上游价值定义}、{中游效率控制}、{下游边界扩张}"的格局。
```

## Content Structure
```
Hook: 一句话定义产业链本质 + 三段式结构预告
↓
图1: 产业链全景图（上中下游分层）
↓
图2-N: 每层详细拆解（参与者 + 盈利方式 + 关键数据）
↓
末图: 核心结论 or 趋势判断
↓
正文: 仅补充图片无法表达的背景逻辑（≤3行）
```

## Information Flow
- order: mechanism_first（先给结构，再填细节）
- density: high（每张图信息量饱和）
- cognitive_load: medium（有结构框架降低认知负担）

## Case Strategy
- type: real industry data
- position: embedded in each section
- function: proof of mechanism

## Text Body Rule
正文 ≤ 3 行，仅说明：
- 产业链的核心矛盾
- 最反直觉的一个环节
- 或系列编号说明

# Template B: Contrarian Framework (反直觉框架型)

Inspired by: 管理者一定要闲 + 把自己当成一家公司来经营

**Applicable scenarios:**
- Counterintuitive business/management insights
- Reframing common knowledge
- Framework-driven explanations

## Title Pattern
```
{反直觉结论}❗{强调词}❗{强调词}❗
为什么{普遍认知}是错的？
{反常识结论}，{补充说明}
```

## Hook Pattern
```
关于{主题}，{权威来源/常识}有一个经典观点：
{普遍认知的正面表述}。
这里的"{核心词}"并非{字面误解}，
而是{重新定义}。
```
或：
```
一、到底什么是「{核心概念}」？
简单来说，就是{一句话定义}，
这套模式最大的好处是{核心价值}。
```

## Content Structure
```
Hook: 反直觉核心观点 + 重新定义
↓
维度拆解（3-4个维度，每维度：闲于X，忙在Y）
↓
图片：每个维度一张卡片，文字+图示
↓
结尾：进阶思维 or 行动建议
↓
互动：开放性问题（非强制）
```

## Information Flow
- order: conclusion_first（先给反直觉结论，再解释为何成立）
- density: medium
- cognitive_load: medium（熟悉主题，降低认知门槛）

## Writing Rhythm
```
信息段：维度标题（一行）+ 解释（2-3行）
情绪段：与读者处境共鸣（1-2行）
信息段：下一个维度
行动段：具体可执行建议
```

# Template C: Knowledge Simplification (知识大白话型)

Inspired by: 毫不夸张，姐的会计科目已经到了秒懂的程度

**Applicable scenarios:**
- Professional knowledge made accessible
- Exam/certification prep content
- Terminology translation

## Title Pattern
```
毫不夸张，{夸张程度表达}已经到了{效果}的程度
别再{错误行为}啦，{受众}的福音来啦
{数量}个{专业词}大白话，{零基础受众}必看
```

## Hook Pattern
```
🔥别再{错误方法}啦，{受众标签}的福音来啦，
{简洁价值承诺}，每个都是{效果承诺}！
⛳{使用场景1}
⛳{使用场景2}
```

## Content Structure
```
Hook: 痛点释放 + 价值承诺（2-3行）
↓
图1-N: 每张图 = 一个知识点
  格式：[术语] → [大白话解释] + [记忆技巧/类比]
↓
正文: 仅放话题标签，图片承担全部内容
```

## Key Rules
- 图片是内容载体，正文可以极简（甚至只有标签）
- 每张图一个概念，不堆砌
- 大白话 = 用日常生活类比替换专业术语
- 表情符号作为视觉分隔符，不过度使用

# Template D: List Framework (清单框架型)

Inspired by: 10大经典商业模式 & 4个演化趋势

**Applicable scenarios:**
- Classification and taxonomy content
- "N种类型"系列
- Pattern comparison content

## Title Pattern
```
{N}大{分类对象} & {M}个{规律/趋势}
一图看懂{N}种{对象}
{N}个{概念}，{受益人}必须知道
```

## Hook Pattern
```
{系列说明/背景交代}
本期笔记梳理了{N}大{分类对象}
[关键图示]示意图以及常见案例总结在图1中：
```

## Content Structure
```
图1: 全景分类图（N种类型一览）
图2-N: 每种类型详解（名称 + 定义 + 典型案例）
末图: 演化趋势 or 选择建议
↓
正文: 系列背景说明 + 图片导航说明（≤5行）
```

## Series Design
- 系列编号增强持续追踪动机
- 每期聚焦一个子主题，不贪多
- 末尾预告下期，建立连载预期

# Template E: Utility Tool (工具实用型)

Inspired by: 财务会计常用的函数公式

**Applicable scenarios:**
- Tool/resource sharing
- Formula/checklist/template sharing
- "工具箱"类内容

## Title Pattern
```
{职业/场景}常用的{工具类型}
收藏！{N}个{受众}必备的{工具}
{受众}必装的{N}个{工具}
```

## Hook Pattern
（极简，正文几乎为空，图片即内容）
```
仅放话题标签
或：一句话说明用途
```

## Content Structure
```
图1-N: 每张图 = 一个工具/公式/模板
  格式：工具名 + 用法 + 示例截图 or 公式展示
↓
正文: 仅话题标签（图片承担100%内容）
```

## Key Insight
这类内容的核心驱动力是**收藏价值**而非阅读价值。
设计原则：让用户感觉"这个以后会用到，先收了"。
图片必须能独立使用，脱离平台也有价值。

# Cross-Template Rules

## Universal Hook Prohibitions
禁止使用以下开篇：
- "今天来分享一下..."
- "大家好，我是..."
- "最近发现一个..."（无具体内容）
- 纯情绪性开场（"太开心了！"）

## Universal Title Rules
- ≤ 20 字
- 包含数字 or 反直觉词 or 明确受益人
- 禁止模糊标题（"这个很重要"、"分享一个方法"）

## Image-Text Relationship (Critical)
- 图片收藏率 > 点赞率时 → 图片是主要价值载体，正文可极简
- 评论率高时 → 正文需要建立情绪共鸣和互动引导
- 转发率高时 → 内容具有社交货币属性，强化"分享给别人"的设计

## Engagement Design
每篇最多一个互动引导，且必须与内容强相关：
- 产业链型：「你们行业的产业链是什么样的？」
- 反直觉型：「你身边有这样的管理者吗？」
- 知识型：「还有哪些概念想看大白话版？」
- 工具型：（无需互动引导，收藏即是目标行为）
